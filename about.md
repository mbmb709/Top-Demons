# Top Demons

Browse the current **Top 150 hardest demons** without leaving Geometry Dash.

Top Demons adds a large **Top 150** button with an Extreme Demon face to the
Creator menu. The list keeps every level in ranking order and provides search,
placement filters, creator filters, paging, random navigation, and quick
refresh.

Before showing the list, Top Demons verifies each Geometry Dash ID and accepts
only rated Extreme Demons with the expected name. If an ID points to an unrated
copy or a different level, it searches for the valid rated level with the same
name.

Choose any result to open its normal Geometry Dash level page. Level
information is cached for up to 30 minutes, and the refresh button can reload
the ranking at any time.

An internet connection is required when the ranking or level information is
not already cached.
