# v1.0.0

- First release of Top Demons.
- Added a large Top 150 button with an Extreme Demon face to the Creator menu.
- Added the current ranking positions 1 through 150 in their original order.
- Added pre-display verification for rated Extreme Demon status and level name.
- Added automatic replacement of invalid IDs with the valid rated level that
  has the same name.
- Added search by level name or ID, placement filters, creator filters, paging,
  random navigation, and quick refresh.
- Added direct access to each demon's Geometry Dash level page.
